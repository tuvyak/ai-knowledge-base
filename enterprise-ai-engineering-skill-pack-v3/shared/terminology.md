# Shared Terminology

- **FACT** — Verified information supported by evidence.
- **ASSUMPTION** — Unverified input used temporarily.
- **DECISION** — Selected approach and rationale.
- **RISK** — Uncertainty that may affect objectives.
- **TBD** — Required information not yet known.
- **Gate** — Condition that blocks or constrains completion.
- **Validation** — Evidence that requirements were checked.
